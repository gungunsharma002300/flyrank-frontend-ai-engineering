Duration & easing notes

  • Content swap (idle ↔ loading ↔ success ↔ error): 200ms, cubic-bezier(0.4, 0, 0.2, 1) — a quick, decisive ease-out. States don't linger mid-fade; a button either clearly is something or is becoming the next thing.
  • Width reflow: 260ms on the same curve, measured via FLIP so the pill resizes to fit new content without ever clipping a label.
  • Loading spinner: 800ms linear, infinite — linear because a spinner promising "in progress" shouldn't ease, or it reads as slowing down.
  • Success check: a 260ms stroke draw, cubic-bezier(0.65, 0, 0.35, 1), so the mark appears to be drawn rather than switched on.
  • Error shake: 380ms, four-keyframe horizontal displacement — short and physical, like a door that won't open, then settles.
  • Reduced motion: every duration above collapses to a 90ms opacity crossfade. Width still resizes (no animation, just the new size), the spinner becomes a static pulsing dot instead of a rotation, and the shake is dropped entirely — the state itself (icon + label + color) still changes, so nothing about the feedback is lost, only the choreography.

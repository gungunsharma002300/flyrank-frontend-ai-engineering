# Signature Hero — Aurora Shader (FE-AA3)

A fullscreen, hand-written GLSL fragment shader hero — no video, no image,
every pixel painted live by math. Built for the FlyRank AI Internship,
Week 8.

**Author:** Gungun Sharma — BCA, AI Engineering Intern

## What it is

A slow, ink-like color field — closer to a studio backdrop than a
rainbow — that drifts on its own and quietly leans toward the cursor.
Restrained on purpose: a single copper accent settling through near-
black and deep indigo, rather than a busy multi-color light show. It's
rendered as a single fullscreen triangle (`gl_VertexID`-based, no
vertex buffer needed) with the entire look generated in the fragment
shader — noise, color, vignette and film grain, all computed per
pixel, per frame.

## How it works (plain-English walkthrough)

The full commented source is in `src/shader.js`. Summary of each block:

1. **`hash(p)`** — turns a 2D point into a pseudo-random number. This is
   the seed everything else is built on.
2. **`noise(p)`** — smoothly blends between four random corner values
   across a grid cell, turning the harsh randomness of `hash` into soft,
   blobby shapes instead of static-like noise.
3. **`fbm(p)`** (fractal Brownian motion) — stacks 5 layers of that noise
   at increasing frequency and decreasing strength. This is what gives
   the aurora its layered, wispy "curtain" texture instead of looking
   like a single smooth blob.
4. **Mouse influence** — the sampling point is shifted a little toward
   the (smoothed) cursor position before the noise is evaluated, so the
   whole flow field visibly leans your way without ever snapping.
5. **Time-based flow** — two `fbm` samples are taken, offset differently
   over time, and blended — one drives the main upward drift, the other
   adds a slower horizontal sway.
6. **Color** — the resulting noise value is remapped through three
   `smoothstep` gradients into a near-black → deep indigo → copper →
   soft highlight palette — one accent color doing the work, kept
   deliberately restrained — with a vertical vignette so it reads as a
   hero backdrop rather than a flat, edge-to-edge texture.
7. **Grain** — a final per-pixel dither breaks up banding on the smooth
   color ramps and adds a bit of texture, per the brief's "grain pass"
   suggestion.

`u_time`, `u_resolution`, and `u_mouse` are all three used (the brief
asks for at least two).

## Ships responsibly

- **`prefers-reduced-motion`**: if set, the shader renders exactly one
  static frame at `t = 0` and the `requestAnimationFrame` loop is never
  started — with a visible "enable the animated version" button for
  anyone who wants to opt in anyway. If the OS setting changes mid-
  session, the page reacts live.
- **Tab visibility**: the render loop is cancelled on
  `visibilitychange` when the tab is hidden, and resumed when it's
  visible again — no GPU/battery burned in a background tab.
- **`devicePixelRatio` capped at 2** — the fragment shader runs once per
  physical pixel, so an uncapped 3–4x phone DPR would multiply the
  per-frame cost for zero visible benefit.
- **Text contrast**: a soft radial vignette sits behind the hero text
  (`::before` in `src/style.css`) so the headline stays readable no
  matter what colors the aurora is painting underneath at that moment.
- **No WebGL2 fallback**: if the browser can't create a WebGL2 context,
  the canvas is hidden and a plain CSS radial gradient takes its place
  — still on-brand, zero JavaScript risk.

## Stack

Vanilla JS + raw WebGL2 + GLSL — deliberately no framework. The whole
production bundle is **~7 KB gzipped total** (JS + CSS), because the
entire visual is generated by the shader itself with no textures or
libraries to ship.

## Run it locally

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # production build -> dist/
npm run preview   # serve the production build locally
```

## Deploy (Vercel)

```bash
npm install -g vercel   # if you don't have it
vercel --prod
```

Or push to GitHub and import at [vercel.com/new](https://vercel.com/new)
— Vercel auto-detects Vite.
